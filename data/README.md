# data/ — your export & import files

Keep your Excel exports, CSV exports and JSON backups in this folder.

- **Export** (Data → Export Excel / JSON / CSV): your browser saves downloads to
  its own Downloads folder — move the files here afterwards for safekeeping.
- **Import** (Data → Import): pick files from here when restoring on this
  computer or after moving them to another machine.

Suggested filenames (the app already names them this way):

```
focus-export-2026-08-07.xlsx     ← for Google Sheets / Excel
focus-workout-2026-08-07.json    ← full backup, moves between computers
focus-workouts-2026-08-07.csv    ← simple spreadsheet
```
